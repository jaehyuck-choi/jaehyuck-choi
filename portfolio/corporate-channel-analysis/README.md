# 법인 고객 대면·비대면 채널 이용 변화 분석

> iM뱅크 iM DiGital Banker Academy 통계 프로젝트 · 5조 · 2026.09.21 ~ 10.07
> **팀장 · 프로젝트 총괄, 전처리·시각화, 가설 정의·검증, 발표**

iM뱅크는 시중은행 전환 뒤 전국 영업망을 넓혀야 하지만, 지역마다 점포와 인력을 늘리는 방식은 시간과 비용이 많이 듭니다(판관비 2023→2024년 +4.56%, 2024→2025년 +3.14%).
그래서 비대면 채널에 주목했고, 다음 질문에 데이터로 답하려 했습니다.
**어떤 법인이 비대면으로 옮겨 가고, 어떤 법인이 창구로 돌아오며 거래가 약해지는가?**

> 인과관계를 밝히는 분석은 아닙니다. 특정 특성이 비대면 확대나 거래 약화와 **함께 나타나는지**를 확인하는 데까지가 범위입니다.

---

## 30초 요약

- **데이터:** iM뱅크 교육용 법인 익명데이터. 법인 15,473개, 법인당 최대 36개월의 월별 패널, 항목 70개
- **분류:** 창구·비대면을 처음과 마지막으로 쓴 달을 비교해 법인을 이용행태 6개로 나누고, 병행 법인 7,197개는 추세에 따라 7유형으로 다시 나눴습니다.
- **검정:** 가설 27개를 정규성·등분산 결과에 따라 t검정, Mann-Whitney, Welch ANOVA, Kruskal-Wallis, 카이제곱, Fisher 정확검정 중에서 골라 검정했고, 효과크기와 다중검정 보정까지 확인했습니다.
- **결과:** 창구를 떠나는 것은 은행을 떠나는 게 아니었고, 창구로 돌아오는 것은 거래가 약해지는 신호였습니다.
- **활용:** 초기 6개월 정보로 비대면 확대 고객을 미리 고르는 기준을 만들었습니다. 이 기준으로 고른 22개 법인 중 17개(77.3%)가 실제로 비대면 이용을 늘렸습니다(기준 없이 고를 때 11.0%).

## 주요 결과

| 질문 | 결과 |
|---|---|
| 창구→비대면 법인은 창구유지 법인과 무엇이 다른가 | 이동 후 자동이체 건수 +23.1%(p=0.0026). 은행관계규모 중앙값 605 vs 227(p=0.00016), 총대출잔액 약 2배 |
| 비대면→창구 법인은 무엇이 달라지나 | 이동 후 요구불 잔액 −62.7%, 월평균 거래건수 약 8건 → 1.7건, 금융영역수와 운전자금대출 감소(모두 p<0.05) |
| 병행 7유형을 가장 잘 가르는 변수는 | 자동이체 이용월비율(ε²=0.150, 효과 큼). 여신·외환 보유 여부는 효과가 거의 없음 |
| 비대면 확대 고객을 미리 고를 수 있나 | 초기 비대면 비중 50% 미만 고객의 확대 비율 35.7%로, 50% 이상(7.1%)의 약 5배. 병행 고객 중 자동이체 월 18.33건 이상이면 77.3% |

## 인사이트

1. **창구 이탈은 은행 이탈이 아니다.** 비대면으로 옮긴 법인은 원래 은행과 관계가 깊었고, 옮긴 뒤 자동이체도 늘었습니다.
2. **창구로 돌아오는 것은 거래 약화의 신호다.** 이 변화 자체를 이탈 조기 경보로 쓸 수 있습니다.
3. **자동이체는 디지털 관계를 잇는 핵심 고리다.** 세 분석 모두에서 같은 결과가 반복해서 나왔습니다.

## 검정 방법 선택 규칙

| 상황 | 기본 방법 | 가정이 깨질 때 |
|---|---|---|
| 같은 법인의 전·후 비교 | 대응표본 t검정 | Wilcoxon 부호순위 |
| 두 집단 비교 | 독립표본 t검정 | 등분산 위반 → Welch t / 정규성 위반 → Mann-Whitney U |
| 세 집단 이상 | 일원 ANOVA | 등분산 위반 → Welch ANOVA / 왜도 > 2 → Kruskal-Wallis |
| 범주형 구성비 | 카이제곱 | 기대빈도 < 5 칸이 20% 초과 → Fisher 정확검정 |

- 유의수준은 0.05로 했습니다. 표본이 큰 분석 3(7,197개)은 p값보다 효과크기(η², ε²)로 판단했습니다.
- 여러 변수를 한꺼번에 검정할 때는 본페로니와 Holm 보정을 적용했습니다. 극단치가 있는 금액 변수는 로그 변환, 절사평균, 순열검정으로 결과가 유지되는지 확인했습니다.

공통 검정 함수 예시 (두 독립집단):

```python
def two_group_test(a, b):
    a, b = pd.Series(a).dropna(), pd.Series(b).dropna()
    pa = stats.shapiro(a.sample(min(len(a), 5000), random_state=42)).pvalue
    pb = stats.shapiro(b.sample(min(len(b), 5000), random_state=42)).pvalue
    levene_p = stats.levene(a, b, center='median').pvalue
    if pa >= 0.05 and pb >= 0.05:
        equal_var = levene_p >= 0.05
        stat, p = stats.ttest_ind(a, b, equal_var=equal_var)
        method = 't-test' if equal_var else 'Welch t-test'
    else:
        stat, p = stats.mannwhitneyu(a, b, alternative='two-sided')
        method = 'Mann-Whitney U'
    return method, p
```
